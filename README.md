# ⚖️ Attorney Maze Game

A web-based maze game with a legal theme where you navigate an attorney through procedurally generated mazes to reach the courtroom!

## 🎮 Game Features

- **Procedurally Generated Mazes**: Every maze is unique, created using recursive backtracking algorithm
- **Progressive Difficulty**: Mazes get larger and more complex as you advance through levels
- **Case File Collection**: Collect case files scattered throughout the maze for bonus points
- **Attorney Theme**: Styled with legal/courtroom aesthetics including gold accents and professional colors
- **Responsive Controls**: Use arrow keys or WASD to navigate
- **Statistics Tracking**: Monitor your moves, time, and collected case files
- **Level System**: Progress through increasingly challenging levels

## 🎯 How to Play

1. Open `index.html` in a web browser
2. Use the arrow keys (↑↓←→) or WASD keys to move your attorney (👔)
3. Navigate through the maze to reach the courtroom (🏛️)
4. Collect case files (📂) along the way for bonus points
5. Complete each level to progress to larger, more challenging mazes

## 🎨 Game Elements

- **👔 Attorney** - Your player character
- **🏛️ Courtroom** - The goal/exit of each level
- **📂 Case Files** - Collectible bonus items
- **Dark Walls** - Obstacles you cannot pass through
- **Open Paths** - Areas you can navigate

## 🕹️ Controls

- **Arrow Keys** or **W/A/S/D**: Move the attorney
- **New Game**: Start over from level 1
- **Reset Level**: Restart the current level

## 📊 Statistics

The game tracks:
- Current level
- Case files collected (out of total available)
- Number of moves taken
- Time elapsed

## 🛠️ Technical Details

- Built with vanilla HTML, CSS, and JavaScript
- No external dependencies required
- Maze generation using recursive backtracking algorithm
- Responsive design for different screen sizes
- Smooth animations and professional styling

## 🚀 Getting Started

Simply open `index.html` in any modern web browser. No installation or build process required!
